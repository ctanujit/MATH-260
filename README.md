**Course Objectives:** Predictive models are essential tools used daily in corporate practice and decision-making. This course aims to give students a general overview of the statistical methods used to analyze multivariate data. In particular, the course covers the statistical tools needed to extract relevant information from any dataset. The course presents several standard techniques, including univariate and multivariate regression, principal components analysis, factor analysis, and multifactor analysis. Students are expected to understand how these methods work, how to apply them to a new dataset, and how to interpret the outputs of different algorithms. 

**Course Syllabus:** Topics to be covered in this course include

1. Introduction to MDA
2. Recap of Descriptive Statistics
3. Recap of Probability and Sampling Distributions
4. Basics of Statistical Inference and ANOVA
5. Basics of R and RStudio
6. Relationship Analysis
7. Multiple Linear Regression
8. Model Selection 
9. Multicollinearity
10. Shrinkage Methods: Ridge, LASSO, and Elastic Net
11. Model Adequacy Checking
12. Nonlinear Regression Analysis
13. Transformations and Generalized Linear Models
14. Autoregression Analysis
15. Logistic Regression
16. Singular Value Decomposition
17. Principal Component Analysis
18. Factor Analysis and Market Basket Analysis
19. Linear Discriminant Analysis and QDA
20. Implementations in RStudio
